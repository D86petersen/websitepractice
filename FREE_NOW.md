## Option 2: Fly.io (Fastest - One Command)

```bash
# 1. Install
curl -L https://fly.io/install.sh | sh

# 2. Login
flyctl auth login

# 3. Deploy (from project root)
cd websitepractice
flyctl deploy -a ccna-platform

# 4. Open
flyctl open -a ccna-platform
```
