## 🚀 Quick Deploy Guides

### Method 1: Railway (Copy-Paste to Deploy)
```bash
# Go to: https://railway.app
# Press: "New Project"
# Select: This repository from GitHub
# Click: "Deploy"
# Wait: 2-3 minutes
# Done: ✅
```

### Method 2: Fly.io (3 Commands)
```bash
curl -L https://fly.io/install.sh | sh
flyctl auth login
flyctl deploy -a ccna-platform
```

### Method 3: Oracle (Most Manual, Freest Forever)
```bash
# 1. Create Oracle account (oracle.com/cloud/free)
# 2. Create Ubuntu 22.04 instance (ARM, always-free)
# 3. SSH in: ssh -i key.pem ubuntu@IP
# 4. Install Docker: curl -fsSL https://get.docker.com | sudo sh
# 5. Deploy: ./scripts/deploy-docker.sh build && start
```
